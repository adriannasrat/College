# System Maintenance and Test of IT Systems

This repository contains my complete work for the course **System Maintenance and Test of IT Systems**.  
It is intended both as documentation of my own learning and as a resource for other students who want to review course material, assignments, and examples.

All course-related material is included and organized so it can easily be downloaded and reused for study purposes.

---

## Course Overview

The course focuses on:
- Software testing principles and methodologies
- System maintenance and quality assurance
- Accessibility and usability testing
- Test planning, test cases, and defect reporting
- Applying theory (e.g. ITIL, WCAG) to real-world systems

A strong emphasis was placed on **practical testing work**, structured documentation, and critical reflection.

---

## What I Worked On

During this course, I completed and contributed to the following:

### Labs
- **Lab 1 & Lab 2 – Test Plan and Test Cases**
  - Created a full test plan using the provided template
  - Designed accessibility-focused test cases based on personas
  - Applied WCAG 2.1 Level AA criteria
  - Documented scope, quality objectives, methodology, roles, and results

### Personas & Accessibility Testing
Testing was performed from multiple user perspectives, including:
- Visual impairment
- Motor difficulties
- Active mobile user
- Inexperienced computer/mobile user

Each persona had dedicated test cases and accessibility considerations.
