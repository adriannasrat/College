# Distributed Computing

This folder contains laboratory assignments and reports completed during the **Distributed Computing** course at Dalarna University.

The course explored distributed systems through software agents, Internet of Things (IoT) and cloud computing. The assignments combined theory and practical implementation, focusing on how distributed components communicate, process data, make decisions and scale across different environments.

## Lab 1 – FSM Game

The first lab focused on software agents and finite state machines using the **SPADE framework**.

### Topics Covered

- Software Agents
- Multi-Agent Systems
- SPADE Framework
- Finite State Machines (FSM)
- Agent Behaviors
- State Transitions

### Assignment

A game was developed using an FSM consisting of at least six states, including start and end states. The objective was to design a state-driven application that demonstrated how software agents transition between different behaviors based on events and conditions.

The lab also included a literature study where peer-reviewed research related to software agents, FSMs or agent behavior was analyzed and discussed.

### Skills Practiced

- Python Development
- Agent-Based Systems
- State Machine Design
- Research Analysis
- Software Architecture

## Lab 2 – IoT Data Analytics

The second lab focused on Internet of Things (IoT) data analysis and forecasting using sensor data from a smart indoor climate environment.

### Topics Covered

- Sensor Data Processing
- Exploratory Data Analysis (EDA)
- Time Series Features
- Forecasting
- Machine Learning
- Automation

### Assignment

Using a real-world smart home dataset, sensor readings such as indoor temperature, outdoor temperature, humidity and appliance energy consumption were analyzed.

The work included:

- Data preprocessing and cleaning
- Feature engineering
- Data visualization
- Building forecasting models
- Evaluating predictions using MAE and RMSE

A simple forecast-based control system was then implemented to automatically control a heating device based on predicted indoor temperatures.

### Skills Practiced

- Python
- Pandas
- Data Visualization
- Machine Learning
- Forecasting
- Automation Logic

## Lab – Cloud Computing

This lab focused on cloud infrastructure, scalability and performance benchmarking using Microsoft Azure Virtual Machines.

### Topics Covered

- Cloud Computing
- Virtual Machines (VMs)
- Scalability
- Resource Allocation
- Performance Analysis
- Cost Optimization

### Assignment

Two Azure Virtual Machines with different hardware configurations were evaluated by executing identical computational workloads.

The analysis included:

- Execution time measurements
- Performance comparisons
- Cost calculations
- Speedup analysis
- Resource utilization

The results demonstrated how cloud resources can be scaled depending on workload requirements and how performance and cost must be balanced when selecting computing resources.

### Skills Practiced

- Microsoft Azure
- Cloud Infrastructure
- Benchmarking
- Performance Analysis
- Cost Analysis
- Scalability Evaluation
