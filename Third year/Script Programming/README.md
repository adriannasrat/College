# Script Programming

This folder contains labs, project material, and the final project report from the Script Programming course.

The course focused on practical scripting using Python, with emphasis on data handling, automation, web scraping, API usage and exploratory data analysis.

## Contents

- `Lab 1/` – Introductory scripting exercises
- `Lab 2/` – Data handling and Python scripting
- `Lab 3/` – Working with files, data formats, or external data
- `Lab 4/` – More advanced scripting and data processing
- `Lab 5/` – Web scraping/API-related work
- `Project/` – Final EDA project
- `Project Report/` – Written report describing the project, method, results, and conclusions

## Final Project

The final project focused on **Exploratory Data Analysis (EDA)**. The work involved collecting or preparing data, cleaning and transforming it, analyzing patterns and presenting insights through visualizations and interpretation.

## Skills Practiced

- Python scripting
- Data cleaning and transformation
- File handling
- Web scraping/API usage
- Exploratory Data Analysis
- Data visualization
- Structuring code and reports
