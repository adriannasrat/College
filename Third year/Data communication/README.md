The course consisted of a practical networking lab, oral and practical examination and a written examination.

## Lab 1 – Build a Switch and Router Network

The practical lab focused on designing, configuring and verifying a small network consisting of:

- One Cisco Router
- One Cisco Switch
- Two Client Computers

### Topics Covered

- IPv4 Addressing
- IPv6 Addressing
- Router Configuration
- Switch Configuration
- VLAN Configuration
- Default Gateways
- Static Address Assignment
- Connectivity Testing
- Network Troubleshooting

### Assignment

The network was configured according to a predefined topology consisting of:

```text
PC-A ── Switch ── Router ── PC-B
```

The work included:

- Cabling the network
- Configuring IPv4 addresses
- Configuring IPv6 addresses
- Configuring router interfaces
- Configuring switch interfaces
- Configuring VLAN 1
- Setting hostnames and passwords
- Enabling IPv6 routing
- Creating login banners
- Verifying end-to-end connectivity

After configuration, connectivity was verified using ping tests between all devices in the network.
