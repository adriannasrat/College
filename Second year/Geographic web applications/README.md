# Web-based Geographic Information Systems (GIS)

This repository contains all assignments, labs, workshops, and the final project from the course **Web-based Geographic Information Systems (GIS)** at Dalarna University. The course focused on web-based geospatial development using **Leaflet.js**, as well as spatial data analysis in **QGIS**.

---

## Folder Structure Overview

### `Assignment 1/`  
A basic Leaflet map with interactive markers, popups, zoom control, and multiple base layers. Introduced foundational Leaflet concepts such as:
- Tile layers and attribution
- Adding GeoJSON features
- Layer control

### `Assignment 2/`  
Expanded functionality with:
- Custom icons and data layers
- GeoJSON parsing and styling
- Filtering and interactivity (click, hover, popups)
- Modular JS with `taskLayers`, `taskControls`, and `main.js`

---

### `Lab 1 - GIS/`  
Worked in **QGIS** to perform vector data operations:
- Loading shapefiles (e.g. Swedish municipalities)
- Attribute joins
- Buffer zones
- Selection by location
- Creating layers for spatial queries

### `Lab 2 - GIS/`  
Focused on **spatial analysis of GPS data**:
- Heatmaps of spatial intensity
- Point clustering and displacement
- Line-based speed variation mapping
- Time-enabled visualizations

---

### `Project/`  
The final group or individual project using Leaflet or QGIS. Included:
- A complete interactive web map
- Modular JS structure and dynamic data
- Map-based storytelling or analysis
- Optional spatial data analysis or download/export functionality

---

### `WS1/` – Workshop 1  
Focus on working with **vector data** and applying basic analysis like:
- Measuring distances/areas
- Filtering with expressions
- Styling based on attributes

### `WS2/` – Workshop 2  
Focus on **raster data** and symbology:
- Using digital elevation models (DEM)
- Hillshade and slope visualization
- Reclassification and raster calculations

---

## Tools & Technologies

- **Leaflet.js** – Lightweight JS library for interactive maps  
- **QGIS** – Desktop GIS platform for spatial analysis  
- **HTML/CSS/JavaScript** – Frontend structure for Leaflet apps  
- **GeoJSON** – For representing geographic features and properties  
- **Shapefiles / CSV / DEM** – Used for vector and raster data in QGIS

---

## Learning Outcomes

- Build interactive web maps using Leaflet and GeoJSON  
- Perform spatial analysis in QGIS using real-world datasets  
- Style and filter spatial layers dynamically  
- Communicate geographic insights through both web and desktop GIS
