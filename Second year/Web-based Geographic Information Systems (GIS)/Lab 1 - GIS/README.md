# Lab 1 – Thematic Maps

The focus was on this lab was creating **thematic maps** using QGIS, applying fundamental cartographic principles and spatial joins.

---

## Lab Overview

The goal of this lab was to learn how to produce **choropleth maps**, **proportional symbol maps**, and **dot density maps** based on demographic data for Swedish municipalities (*kommuner*).

---

### Task 1 – Choropleth Map (Average Age 2020)

- Displayed the **average age** per municipality in 2020.
- Used the **"Join Attributes by Field Value"** tool in QGIS.
- Applied appropriate color gradients to represent values.

### Task 2 – Proportional Symbol Map (Population Size 2020)

- Used **graduated symbols** to show population sizes.
- Joined attribute data to geographic features.
- Scaled circle sizes proportionally to population values.

### Task 3 – Choropleth Map (Population Change 2011–2015)

- Visualized **population change** across municipalities.
- Used a calculated field (P2015 – P2011).
- Applied diverging color scale to indicate increase/decrease.

### Task 4 – Dot Density Map (Municipal Population)

- Created a **dot density map** using:
  - `Random points inside polygons` tool
  - One dot = a fixed number of residents
- Displayed population distribution visually across space.

---

## Data

All source data was provided in the `Data-1.zip` package available on the college platform used at the time by the teacher responsible for the course.

---

## Map Requirements

All final maps included:

- Title  
- Legend  
- North arrow  
- Scale bar  

Maps were exported and submitted as **PDF files**.

---

## Learning Outcomes

- Use of spatial joins in QGIS
- Understanding visual representation techniques
- Applying symbology and design principles in thematic mapping
- Exporting clean, publication-quality maps

---
