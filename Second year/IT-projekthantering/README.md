# IT Project Management

This course introduced the fundamentals of managing IT projects, both in group work and individual assignments. The work was divided into two main parts:

- **A group project** following a traditional project model with phases such as pre-study, planning, execution, and handover.
- **Individual financial management**, where we practiced budgeting, cost analysis, and interpreting results through hands-on exercises.

---

## Course Structure

### `Uppgift/` *(Group Project)*  
This folder contains all material related to the group project based on a case from a fictional company:  
**Datadalens Sporthotell och skiduthyrning AB**.

- `Förstudie/` – Stakeholder analysis, needs analysis, SWOT, goal formulation  
- `Planering/` – Project plan, timeline, WBS (Work Breakdown Structure), resource allocation  
- `Genomförande/` – Risk management, monitoring, and change management  
- `Överlämning/` – Final report, reflection, and project closure  
- `Projektuppgift/` – Contains the assignment description and company presentation (PDF)

---

### `Ekonomistyrning/` *(Individual Assignment)*  
Contains two separate workshops with accompanying Excel files where we worked with budgeting, revenue estimation, and cost tracking.

- `Workshop 1/` – Focus on basic budgeting and cost types  
- `Workshop 2/` – Outcome analysis and comparison with budget

---

## Methods & Tools

- Project model: Phase-based (pre-study → planning → execution → handover)  
- Financial management: Operating budget, cost analysis, Excel models  
- Tools: Microsoft Word, Excel, Microsoft Teams, Gantt charts  
- Agile elements based on course literature (e.g., Scrum, Kanban)
