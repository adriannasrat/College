# Data Science and Machine Learning

This course introduced practical data science and machine learning workflows using Python. The focus was on understanding the entire pipeline: from data preprocessing and visualization to applying statistical tests, clustering, and predictive modeling.

The course included both guided lab assignments and a final independent project.

---

## Folder Structure

### `Labs/`  
Contains structured Jupyter notebooks for each lab assignment, covering the core data science steps:

- `Task 1 – Data Cleaning and Exploration`  
  - Handling missing values, outliers, scaling, encoding
  - Descriptive statistics, distribution plots, boxplots

- `Task 2 – Visualization and Correlation`  
  - Correlation matrices, scatter plots, heatmaps, histograms
  - Group-wise analysis and comparisons

- `Task 3 – Hypothesis Testing`  
  - One-sample and two-sample t-tests  
  - ANOVA, Tukey HSD, Shapiro-Wilk normality test  
  - Chi-square tests and assumptions

- `Task 4 – Clustering and Classification`  
  - K-means clustering, silhouette scores  
  - Logistic regression, decision trees, confusion matrix  
  - ROC/AUC and model evaluation

- `Task 5 – Regression and Prediction`  
  - Linear and polynomial regression  
  - RMSE, R² score, residual analysis

---

### `Final Project/`  

Topic example:  
> **Laptop Price Fairness**  
> A comparison of laptop prices between two Swedish retailers (Elgiganten vs Komplett), including web scraping, clustering by specifications, and statistical testing of price differences.
